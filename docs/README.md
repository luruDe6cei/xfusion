# docs/

Product / requirements documents for the xFUSION 2.0 work.

**The documents themselves are deliberately NOT tracked in git** — they're
proprietary client material, and one is a 3.6 MB binary. `.gitignore` excludes
`docs/*.pdf`, `docs/*.docx`, `docs/*.doc`. This README is tracked so the folder
(and the fact that these documents exist) survives a clone.

| File | What it is |
|------|-----------|
| `xfusion-2.0-specification-en.pdf` | xFUSION 2.0 specification — English translation. |
| `xfusion-2.0-improvements-he.docx` | מסמך אפיון — improvements & additions to the system (Hebrew original). Was named `AK+NB…(2).docx`. |

If you're picking this project up on a new machine, get these from whoever owns
the engagement and drop them in here — nothing in the build depends on them, but
they define the roadmap in `HANDOFF.md`.
